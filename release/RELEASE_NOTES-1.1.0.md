# Better Agnostr 1.1.0 — Suite shortcut, group switcher, and serif fonts

**The Better Agnostr shortcut now lives in the Agnostr Suite, the groups page has its own compact switcher, and the font picker has six new serif families.**

## Changed

- Removed the dedicated Settings and Better Agnostr buttons from the profile footer.
- Moved **Better Agnostr** into the Agnostr Suite footer, available on every page.
- Rebalanced the suite footer so **Better Agnostr** and **Settings** share the row evenly.
- Added a simplified groups-page switcher with joined-group buttons, a create/join button, and the Agnostr Suite button inline with the group buttons.
- Moved the stars shooting star further left and extended its travel so it is more noticeable.
- Prevented the generic rainbow palette from flashing while a flair-specific rainbow is active.
- Added six bundled serif fonts: Playfair Display, Cormorant Garamond, Libre Baskerville, Lora, Fraunces, and Instrument Serif.

## Downloads

- `better-agnostr-1.1.0.xpi` — installable package. This build is **unsigned**; Firefox Release/ESR requires Mozilla signing for permanent installation.
- `better-agnostr-1.1.0.zip` — packaged source for review or AMO signing.
