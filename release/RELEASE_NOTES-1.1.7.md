# Better Agnostr 1.1.7 — Restore the native app rail

**This hotfix restores Agnostr's native desktop app rail after the latest Agnostr layout update.**

## Fixed

- Restored the native app rail and its workspace, group, suite, search, settings, install, and profile controls.
- Removed the rule that hid the entire rail.
- Removed the custom groups-page rail, which was duplicating the native rail after the update.
- The groups page now uses Agnostr's own group switcher and create/join controls.
- Kept the 1.1.6 mobile settings-pane fixes.

## Downloads

- `better-agnostr-1.1.7.xpi` — installable package. This build is **unsigned**; Firefox Release/ESR requires Mozilla signing for permanent installation.
- `better-agnostr-1.1.7.zip` — packaged source for review or AMO signing.
